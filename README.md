# arduino-lcd-and-temp-sensor

This repository provides the C++ implementation for a combined digital clock and thermometer built on the ATMEGA328P architecture (Arduino Uno). The project reads ambient temperature from an LM35 sensor using the internal ADC module and calculates elapsed time via hardware interrupts generated by Timer1. The system updates a 16x2 LCD screen exactly once per second using the LiquidCrystal.h library to simultaneously display the tracked time and current temperature data.
